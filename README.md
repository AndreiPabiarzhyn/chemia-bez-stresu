# Chemia bez stresu

## Локальный эксперимент: learning-lab

Ветка `codex/learning-lab`: четыре мини-урока с интерактивными моделями и девятью проверками; последовательность карточки → пары → викторина → ввод → смешанная проверка; отдельный язык ответов, объяснения ошибок, произношение польских названий при наличии голоса устройства, сохранение текущего занятия и повторение по результатам.

Самооценка карточек и проверенные ответы учитываются отдельно. Экспериментальные сессии и статистика используют ключи `chemia-lab-*` в localStorage. Повторение ошибочных ответов предлагается сразу, успешно проверенных — через сутки. Это простой локальный алгоритм, не облачная синхронизация.

Запуск на отдельном порту:

```powershell
$env:PORT = "8081"
npm start
```

Открыть http://127.0.0.1:8081/. GitHub Pages этим экспериментом не обновляется.

Небольшой автономный тренажёр по химии для 7 класса польской школы. Первая тема — плотность (`gęstość`).

## Что внутри

- объяснение смысла плотности простым русским языком;
- польские формулировки задач;
- пошаговый пример и проверка;
- 6 интерактивных задач с подсказками;
- польско-русский словарь;
- переключатель тем курса, подготовленный для новых разделов;
- двуязычный интерфейс RU/PL и собственный favicon.
- таблица 24 элементов из тетради и отдельная теория;
- пять игр: переворачиваемые карточки, пары, викторина, ввод символа и поиск лишнего;
- подборки по 8 элементов, повторение ошибок и сохранение отмеченных карточек на устройстве;
- крупное игровое поле, клавиатурный ввод и адаптация для телефона.

Игры находятся в `memory.js`, их оформление — в `memory.css`. Дизайн использует существующие цвета сайта, пастельные панели из Notion DESIGN.md, принципы Wordwall / Genially и переворот Flip Card из Kinetics. `DESIGN.md` импортирован в `CLAUDE.md`; правила проекта имеют приоритет над внешним референсом.

## Запуск

Для обычного режима можно открыть `index.html` в браузере. Для экспериментального режима «Помоги разобраться» запусти локальный сервер:

```powershell
node server.mjs
```

После этого открыть <http://localhost:8080>.

Если задана переменная `OPENAI_API_KEY`, запросы отправляются через OpenAI Responses API с сервера. Ключ не попадает в браузер и не добавляется в репозиторий. Без ключа работает встроенная локальная подсказка по шагам.

Пример для PowerShell:

```powershell
$env:OPENAI_API_KEY = "твой_ключ"
npm start
```

Тесты:

```powershell
npm test
```
